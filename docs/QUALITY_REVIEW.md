# 그래픽·애니메이션·성능 검토

## 수정 내용

- 제갈량: 장포의 좌우 연속 가중치를 유지하면서 보행 회전 키를 33개, 접지 키를 65개로 세분화했다. 골반과 상체에 약간의 위상 차이를 주고 모델을 다시 구웠다. 머리·부채 디테일은 유지했다.
- 보행: 개체별 보정 회전이 뼈에 누적되지 않도록 원래 자세를 복원한다. 클립 길이에 맞춰 보행 위상을 계산하고 모퉁이에서 방향을 부드럽게 전환한다.
- 빙결: 생성 직후 얼어붙은 유닛도 첫 접지 자세를 즉시 적용한다. 최초 페이드가 바인드 자세를 노출하던 문제를 수정했다.
- 전투: 배속과 일시정지를 애니메이션·입자에 반영한다. 성 공격 중 피격 플래시가 해제되지 않는 문제, 프리미티브가 타격 사이에도 계속 찌르던 문제, 회전된 부모 아래에서 공격 방향을 중복 회전하던 문제를 수정했다.
- 사망: 급격한 축소·침강을 완만한 쓰러짐과 지연 페이드로 바꿨다. 원래 반투명한 재질과 발광 강도도 풀 재사용 후 유지한다.
- 입자: 계산만 하던 개별 크기를 실제 셰이더에 연결하고 입자별 투명도를 추가했다. 연기는 팽창·감속·페이드하며, 비활성 시스템은 그리기와 버퍼 갱신을 건너뛴다. 기존 단일 Points 드로우와 고정 용량을 유지한다.
- 프레임 비용: 적·투사체와 체력바 갱신의 반복 선형 검색을 배열 순회 + Map 조회로 바꿨다. 동일한 환경 프리셋의 지형 장식을 중복 생성하지 않는다.
- 자원 수명: 풀의 비활성 유닛·투사체도 장 종료 시 정리한다. 복제된 적과 타워 스켈레톤의 GPU 자원을 해제한다.
- 조명: 태양을 전장에 고정해 카메라 이동에 따라 그림자가 움직이거나 장별 석양 방향이 덮어써지지 않게 했다.
- 검사: 기본 API 변경 이후 실패하던 스모크 로그인은 명시적으로 로컬 계정을 사용한다. 보상 검사는 과거의 고정 시작 골드 대신 전투 전후 골드를 비교한다.

## 검증과 재현

- `npm test`: 28개 파일, 357개 검사. 제갈량의 실제 변형 정점을 65개 보행 시점에서 확인하고 지지발 편차 0.08u 미만, 루프 연결, 정규화된 가중치를 검사한다.
- `npm run typecheck`, `npm run lint`, `npm run build`.
- `npm run smoke -- --url http://localhost:4173`: 빌드한 게임의 로그인·건설·업그레이드·전투·계략·유닛 리깅·발사음·화면 회전 검사.
- `npx tsx scripts/smoke-chapters.ts`: 4~6장 지형·렌더·타워 건설 검사. 개발 서버 5178 사용.
- `node scripts/smoke-mobile.mjs`: 12개 화면 크기와 폴더블 가시 영역, 메뉴·로그인 스크롤 검사.
- `node scripts/smoke-quality.mjs`: 48개 유닛과 화염을 생성한 뒤 3회 재시작. GPU 지오메트리 **60 → 60 → 60**, 텍스처 **68 → 68 → 68**. 일시정지·3배속·입자 셰이더 실행도 검사한다.
- `node scripts/visual-review.mjs`: 실제 제갈량 GLB의 네 보행 자세를 `artifacts/review-zhugeliang-*.png`로 저장한다.

브라우저 검증은 설치된 Chrome의 헤드리스 WebGL 경로로 수행한다. 위 자원 수치는 동일한 테스트 장면에서의 누적 여부이며 실제 휴대폰 GPU의 FPS나 모든 기기의 성능을 보장하는 수치가 아니다. 실험적인 `?gpu=1` 경로는 이번 검증 대상이 아니다.
