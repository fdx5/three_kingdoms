# 3D 모델이 필요한 것들

마지막 갱신: 2026-09-07

게임에 들어간 전용 모델은 **16종**이다. 아래는 아직 아닌 것들 — 프리미티브로
그려지고 있거나, 남의 모델을 돌려쓰고 있다.

## 어떻게 진행하는가

원본(60~90MB `.glb`)을 `img/` 에 넣고 알려 주면 그 다음은 파이프라인이 받는다.
`img/` 는 저장소 밖이다(`.gitignore`) — 커밋되는 것은 굽고 난 결과물뿐이다.

```
img/원본.glb  →  npm run asset:<이름>  →  public/assets/models/<id>.glb
                 (감면 · 인물 분리 · 리깅 · 클립)
                                        →  manifest.json 에 한 줄
                                        →  데이터의 view.modelId
```

리깅은 세 갈래다. 규약은 `docs/ASSETS.md`.

| 갈래 | 스크립트 | 뼈 / 클립 |
| ---- | -------- | --------- |
| 사람·짐승 | `rig-model.ts` | `stand`·팔다리 / `idle` `walk` `attack` `die` |
| 쏘는 건물 | `rig-tower.ts` | `tower` `bowN` `bowN_nock` / `shootN` |
| 지면 함정 | `rig-trap.ts` | `tower` `spikeN` / `idle` `trigger` |

수레(`jz_oxcart`·`sh_supply`)는 셋 중 어디에도 안 맞는다. 걷지도 쏘지도 않고
바퀴가 구른다 — `rig-trap` 을 만들 때처럼 갈래를 하나 더 내야 한다.
