## 2026-09-06 — 중단된 지면 화염 개선 마무리

9월 5일 마지막 요청인 불화살·투석기·성 공격의 지면 화염 개선은 사용량 제한으로 중단됐다.
`FireTextures.ts`와 `GroundFireView.ts`는 작성돼 있었으나 장면 연결이 남아 있었다.

- 화염 구역 ID를 시드로 전달해 착탄마다 불꽃 배치와 움직임을 다르게 적용했다.
- 카메라를 전달해 불꽃·연기·불티가 시점 변화에도 보이도록 연결했다.
- 피해 구역 종료 시 바로 제거하던 처리를 불꽃 → 잔불 → 연기·그을음 소멸로 변경했다.
- 잔여 효과는 최대 2.4초 유지하며 개수 상한과 장면 종료 시 자원 해제를 적용했다.
- 불꽃 갱신 중 매 프레임 반복 생성하던 회전 객체를 재사용한다.
- 기존 스모크 테스트에 새 브라우저의 로그인 단계를 추가했다.

재현 및 검증:

```sh
npm test
npm run lint
npm run build
# 먼저 npm run dev -- --port 5178 로 서버 실행
npx tsx scripts/smoke-ground-fire.ts
npm run smoke
```

지면 화염 전용 브라우저 검증은 네 종류의 생성, 잔여 효과 유지, 최종 제거 및 렌더 오류 없음을 확인한다.
화면 기록: `artifacts/ground-fire-burning.png`, `artifacts/ground-fire-cooling.png`.
전용 단위 테스트는 소멸 수명, 카메라 대응, 착탄별 차이 및 공유 자원 수명을 확인한다.

검증 결과: 단위 테스트 261개, ESLint, 프로덕션 빌드, 지면 화염 전용 브라우저 검증 통과.
전체 스모크는 로그인·건설·업그레이드·보병/두목 렌더까지 통과했으나 기존 성벽 타격 확인에서
`보스가 성에 닿지 않았다` 오류로 종료됐다. 해당 확인은 `attackingViews`를 조회하는 기존 코드이며,
전체 스모크 통과로 간주하지 않는다. 렌더 테스트와 동시에 실행했을 때 발생한 단위 테스트 시간 초과는
브라우저 종료 후 전체 단위 테스트를 다시 실행해 261개 모두 통과함을 확인했다.
