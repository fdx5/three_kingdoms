# Third-party environment assets

The terrain PBR maps below are distributed by Poly Haven under CC0 1.0.
Attribution is not required, but the sources are recorded here for provenance.

- `forest_ground_04_*`: Poly Haven, “Forest Ground 04”
  https://polyhaven.com/a/forest_ground_04
- `forrest_ground_01_*`: Poly Haven, “Forest Ground 01”
  https://polyhaven.com/a/forrest_ground_01
- `sparse_grass_*`: Poly Haven, “Sparse Grass”
  https://polyhaven.com/a/sparse_grass

Each set uses 1K diffuse, OpenGL normal, and roughness maps to keep download
size and GPU memory appropriate for a browser game.

`generated_battlefield_ground.png` was generated for this project with OpenAI
ImageGen and is used as the road surface.
